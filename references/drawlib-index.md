# drawlib Categories and Index (one category, one library)

> `drawlib/` has **11 libraries / 402 items**, **one category per library** (`excali-*`). Built by **image-recognition curation from community/base libraries + reorganization by category** (workflow in `asset-taxonomy.md`, provenance in `manifests/`). This file is the **category taxonomy + retrieval entry point**; the listing/key indices are in `drawlib-catalog.md`, and the machine index is in the root `drawlib-index.json`.
> Asset-first (Principle #2): before drawing, **find first; if it exists, reuse it via data-lib; do not draw by hand.**

## Three ways to search

```bash
node scripts/drawlib-find.mjs pie            # keyword (name/tag/library/category) -> gives the data-lib index
node scripts/drawlib-find.mjs checkbox button
node scripts/drawlib-find.mjs --cat chart    # list all by category
node scripts/drawlib-find.mjs --lib excali-ui # list all by library
node scripts/drawlib-find.mjs --cats         # see all categories + counts
```
Once found: `<div data-lib="libname:index">`. **Indices drift -> before use, run `node scripts/drawlib-sheet.mjs <libname>` to render the contact sheet and verify.**

## Machine index `drawlib-index.json`

Generated by `node scripts/build-drawlib-index.mjs`. Each entry: `{ id:"excali-chart:28", lib, index, name:"Pie", category:"chart", domain, tags, types, elements }`.
- `drawlib-find.mjs` reads it for retrieval;
- `build-drawlib-index.mjs --check` compares old vs new, **exits non-zero if indices/counts drift** (can be wired into CI / release).

## Maintenance

Add/swap/curate a library -> write `manifests/<library>.json` (`include` merges the whole library / `items` curates item by item) -> `node scripts/assemble-lib.mjs manifests/<library>.json` -> `build-drawlib-index.mjs` (rebuild) -> `drawlib-sheet.mjs <library>` (verify indices) -> update this table + `drawlib-catalog.md`. The full pick workflow is in `asset-taxonomy.md`.
